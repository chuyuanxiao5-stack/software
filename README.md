# MisCan Problem（宣教師と人食い問題）

## 概要
このプログラムは、宣教師と人食い問題をDFS（深さ優先探索）およびBFS（幅優先探索）で解くJavaプログラムである。

## 使用技術
- Java

## 機能
- DFSによる探索
- BFSによる探索
- 状態遷移による問題解決
- ゴールまでの経路表示

## 実行方法
Javaファイルをコンパイルし、MisCanProblemクラスを実行する。

## 改善内容（本ブランチ）
このブランチでは、DFS/BFS実装の可読性向上およびコード構造の整理を行った。
具体的には、状態管理部分の整理とコメント追加により、処理の流れを理解しやすくした。

## ブランチについて
本修正はfeature/issue-4ブランチ上で行い、mainブランチに影響を与えない形で開発を行った。
